What the next launches are worth

Every protocol below records no token yet. Each is ranked by an implied value worked out from its own snapshot figures — TVL, seven-day growth, age, chain reach and category — and each row carries the steps to farm it. An implied value is this radar's own claim, never a promise that a token will launch.

How the value is modelled

One function, impliedValue, scores every row from the snapshot alone — no list of names is ever special-cased. For a protocol with TVL T, seven-day change G, age A in days since it was first tracked, C chains and category K:

base         = T x 0.30
growth       = clamp(G, -50, 150) per cent; unknown growth counts as 0
growthMult   = 1 + (growth / 100) x 0.60
ageMult      = 0.70 + 0.30 x min(A, 730) / 730; unknown age counts as 365 days
breadthMult  = 1 + 0.03 x min(C - 1, 4)
categoryMult = 1.05 for fee-capturing categories (Dexs, Lending, Derivatives,
               Yield, CDP, Leveraged Farming, Basis Trading, Yield Aggregator),
               0.95 for wrappers and bridges (Bridge, Canonical Bridge, Liquid
               Staking, Liquid Restaking, Restaked BTC, Staking Pool), 1.00 otherwise
implied      = max(1, round(base x growthMult x ageMult x breadthMult x categoryMult))

Rows are ranked by implied value, highest first, ties broken by slug. Where two rows still tie, the lower one steps down a dollar at a time, so the board is strictly decreasing. The detail view shows every row's own breakdown, so any number on the board can be checked against the snapshot.

Say a protocol records no token, never that it has none: a protocol on the board may still hold a token its DefiLlama record does not carry. Nothing here predicts whether or when a token is issued.
